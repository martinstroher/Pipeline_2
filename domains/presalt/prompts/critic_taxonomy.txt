## How to decide each row — ONE pass, take the FIRST verdict that matches
────────────────────────────────────────────────────────────
Read the NLD as `X is a Y that <differentia>`, then walk these in order:

1. **Proper noun** — names exactly one thing (a field, basin, formation, age, person, event)? → CONVERT_TO_INSTANCE.
2. **Not a domain entity** — a methodology, model, classification scheme, or measurement unit? → DROP_AS_MIXIN.
3. **Bucket the `<differentia>`** into one of: `Quality` (inhering property — colour, density, porosity) · `Disposition`/`Function` (a capacity realised in a process — soluble, stores fluid) · `Role` (externally-grounded function — reservoir, seal, host) · `Site` (a place) · `Process` · `TemporalRegion` · `None` (a genuine structural subkind).
   - **None** → go to 4.
   - **Any other bucket** = the differentia is a separate BFO entity the bearer *has / plays / occupies*, not a subkind (confirm with a rewrite — `<parent> <property> some <differentia>` ≈ the NLD → record as `probe3_rewrite`):
       • a **substantial material bearer** that carries it → **KEEP_AS_BEARER** (keep its genus; `carried_by` the realizable/quality)
       • a throwaway `<genus> + <property>` (e.g. `RedApple`) → **DROP_AS_MIXIN**
       • the term *is* that quality/role/process itself (e.g. `porosity`, `HusbandRole`) → KEEP under that branch
4. **Wrong genus? (OntoClean)** Tag the term with three signs, then REPARENT only on a rigidity or dependence violation:
   - **Rigidity** — `+R` = essential kind it can never stop being (`Person`, `rock`); `~R` = a contingent role/phase it can drop while still existing (`Student`, `reservoir`). *Violation:* `~R` parent over a `+R` child (e.g. `Person` filed under `Student`) → REPARENT onto a rigid genus.
   - **Dependence** — `+D` = exists only via another entity (`role`, `boundary`); `-D` = self-standing (`rock`, `person`). *Violation:* `+D` parent over a `-D` child (e.g. `rock` filed under `role`) → REPARENT onto an independent genus.
   - **Identity** — `+I` = has its own way to tell two instances apart; `-I` = none (normal for quality/role/process). Advisory: record it, never REPARENT on it alone.
   If you can't name a better **existing** genus → KEEP.
5. **Restates its parent?** the differentia is necessary for the genus, so it adds nothing → **DROP_AS_REDUNDANT** (`survivor` = parent).
6. otherwise → **KEEP**. (When unsure, KEEP.)

## Six verdicts (taxonomy rows)
────────────────────────────────────────────────────────────

Each verdict and the field(s) it must carry (the *when* is the decision steps above):

- **KEEP** — parent is a correct genus; nothing to carry.
- **REPARENT** — real term, wrong genus → `new_parent` = a better **existing** class (current parent, a sibling, or an Allowed class). Cite the NLD/relation evidence in `reason`. Can't justify it → KEEP.
- **KEEP_AS_BEARER** — bearer kept under its genus; differentia carried as a companion axiom. **`carried_by` = {{"property", "filler", "filler_nld"}}** by bucket: `Role→has_role`, `Function→has_function`, `Disposition→has_disposition`, `Quality→has_quality` (filler = `<Bearer>Role`/`<Bearer>Function`, or the quality's own name, e.g. `Heterogeneity`). `filler_nld` = a one-sentence Aristotelian definition of that minted filler class in the form "A <genus> that is borne by a <bearer …>" (genus = role/function/disposition/quality), grounded in the bearer's own NLD. `new_parent` optional, reuse-only (omit = keep current; never a realizable, never invented). Substantial bearers only — else DROP_AS_MIXIN.
- **DROP_AS_MIXIN** — term removed. **`carried_by` = {{"property", "filler"}}** records the BFO entity (audit only, not re-emitted).
- **DROP_AS_REDUNDANT** — term removed; **`survivor` = parent**.
- **CONVERT_TO_INSTANCE** — **`target_class`** = best fit from the Allowed list (add `mint_parent` only if none fits).

## Generic worked examples (BFO-spec; not domain-specific)
────────────────────────────────────────────────────────────

- **`Color is a Quality that depends on a material entity`** → bucket `None` (it's the bearer relation that is the meaning); rewrite `Color inheres_in some MaterialEntity`. Verdict: KEEP under `quality`.
- **`Husband is a Man that is married to a woman`** → bucket `Role`; the term **is the bearer** (a Man) that *plays* the husband role, and "husband" is a kind listed in its own right. Verdict: **KEEP_AS_BEARER**, `new_parent: Man`, `carried_by: {{"property": "has_role", "filler": "HusbandRole", "filler_nld": "A role that is borne by a man who is married to a woman."}}` → emits `Husband ⊑ Man` + `has_role some HusbandRole`. (REPARENT under `role` would be wrong — a husband is not a role, he *has* one.)
- **`The year 1969 is a TemporalRegion that contains the first Moon landing`** → step 1: proper-noun individual. Verdict: CONVERT_TO_INSTANCE with `target_class: temporal region`.
- **`RedApple is an Apple that has a red colour`** → bucket `Quality` (the colour inheres in the apple); rewrite `Apple + has_quality some RedColour` preserves truth conditions. Verdict: DROP_AS_MIXIN, `carried_by: {{"property": "has_quality", "filler": "RedColour"}}`.
- **`ColourClassification is a Framework that organises objects by colour`** → step 2: analytical framework. Verdict: DROP_AS_MIXIN, `carried_by: {{"property": "is_about", "filler": "Object"}}`.
- **`FragileVase is a Vase that breaks easily`** → bucket `Disposition` (a capacity realised only when the vase is struck); rewrite `Vase has_disposition some Fragility`. Verdict: DROP_AS_MIXIN, `carried_by: {{"property": "has_disposition", "filler": "Fragility"}}`.
- **`ThreeSidedTriangle is a Triangle that has three sides`** → step 5: the differentia "has three sides" is *necessary* for any triangle (a triangle is *by definition* three-sided), so it adds nothing beyond the parent. Verdict: DROP_AS_REDUNDANT, `survivor: triangle`.
- **`Apple is-a Food`** → step 4 rigidity: parent `Food` is ~R (a thing is *food* only in a consumption context) but `Apple` is +R → REPARENT `Apple` onto a rigid genus (e.g. `Fruit`).
- **`RedThing is-a ColouredThing`** → step 4 identity is **advisory**: both sides are `-I` (colour gives no way to individuate instances) → do NOT REPARENT; record `identity: -I` and KEEP.
