## One authoritative fate per candidate
────────────────────────────────────────────────────────────

- **KEEP_PRIMITIVE** — necessary in the core because it is a broad branch anchor, a genus needed by multiple retained children, a required generic-relation endpoint, contributes CQ coverage not supplied by its parent/siblings, or is an atomic member of a small coherent scientific frame.
- **KEEP_DEFINED** — the same necessary core value, but for a central cross-axis or property-defined concept. Supply `defined_by` using only EXISTING classes/properties. A candidate with `taxonomy_action: KEEP_AS_BEARER` already has its valid definition in `taxonomy_definition`; preserve that action rather than inventing a replacement definition.
- **DEMOTE_TO_PROPERTY** — a useful distinction, but mainly a property/facet value rather than a reusable kind. Supply `demoted_as` for audit; no universal axiom will be added to the base class.
- **DROP_CLASS** — a valid domain term that lacks marginal core value. Supply `drop_basis` as exactly `NO_MARGINAL_VALUE | NARROW_EXTENSION_DETAIL | STACKED_CONTEXT`. Synonymy/redundancy is not a valid basis here.

A genuine kind, conventional technical name, or non-vacuous differentia is NOT sufficient. Ask what the core loses if this class is absent. KEEP only when its CQ contribution, generic relations, branch structure, or indispensable domain distinction is not already represented by its parent/siblings.

**Coherent scientific frames:** shared CQ coverage with a parent is expected for sibling species, taxa, formal ranks, origin classes, and other same-axis kinds. An atomic conventional member of a small frame may be core-worthy when it is corpus-attested and distinctly classifiable on that frame's axis. Set `core_basis: COHERENT_FRAME_MEMBER`, `coherent_frame: true`, name the `frame_axis`, and list existing `frame_siblings`. This does NOT protect modifier-heavy, percentage-defined, geographic, or stacked-context specializations.

**Existing bearer definitions:** `taxonomy_action: KEEP_AS_BEARER` means taxonomy review already separated a material bearer from a role/function/disposition/quality. Never rewrite a role, function, or disposition carry as a quality/property demotion. A complete role/function/disposition bearer is normally `KEEP_DEFINED`; exclude it only when the entire named bearer is a stacked contextual specialization. Quality carries may still be demoted when they are analysis-driven groupings.

Use frequency and CQ evidence as signals, not mechanical thresholds. A rare but central conventional kind may stay; a frequent descriptive phrase may still be demoted. Builder-minted intermediates have zero frequency by design, so judge their grouping value from the branch context.

When evidence is balanced and neither a coherent frame nor a valid realizable-bearer case applies, choose DROP_CLASS and set `needs_review: true`; uncertainty is diagnostic and does not expand the core. Compoundness alone never decides fate. Do NOT drop a term because it is synonymous/co-extensional with a sibling: keep it for the reconciliation stage, which alone chooses the survivor.
