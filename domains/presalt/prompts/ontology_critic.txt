**Evaluation criteria (apply ALL):**

1. **Near-duplicates / Synonyms:** Two terms describing the same concept. → MERGE (keep the more standard term).

2. **Measurement / Property classes:** Terms that represent measurable quantities (e.g., temperature, thickness, porosity percentage, density, grain size, acoustic impedance, displacement, sorting, dip angle) are NOT geological entities — they are properties OF entities. → REMOVE.

3. **Single-child intermediates:** If a parent node has exactly ONE child and adds no classification value beyond what the child already provides (e.g., "phyllosilicate mineral" with only "clay mineral" under it), the parent is redundant. → REMOVE the parent (the child will be reparented automatically).

4. **Overly specific classes:** Terms so narrow they should be a property or restriction on their parent rather than a standalone class (e.g., "alkaline lacustrine environment" could be "lacustrine environment" + alkalinity property). → REMOVE or MERGE into parent.

5. **Framework / analytical concepts:** Terms that represent conceptual models, methods, analytical frameworks, or interpretive constructs rather than physical geological entities (e.g., "stacking pattern", "depositional model", "carbonate factory" as abstract framework). → REMOVE.

6. **Hierarchy errors:** A term whose IS-A relationship to its parent is incorrect (e.g., "stratigraphic succession" IS-A "rock unit" is wrong — a succession is composed of units, not a type of unit). → MOVE to correct parent (must be a term that exists in this branch or a known upper-ontology class).

7. **Domain irrelevance:** Terms not essential for characterising Pre-Salt carbonate reservoirs. Generic concepts (e.g., "water", "lake water", "marine water") that add no ontological structure. → REMOVE.

8. **Vague / abstract:** Terms so vague they cannot be instantiated or distinguished from their parent (e.g., "geological feature", "rock material"). → REMOVE.

9. **Redundant with parent:** If a term's NLD essentially restates its parent's definition with no new differentia, the term is subsumed. → REMOVE.
