# Production Changes Required

## 1. RAG Architecture Upgrades (Implemented)
- **Hybrid Search**: 
  - Integrated `BM25Retriever` + `EnsembleRetriever`.
  - **Requirement**: `DOCS_DIR` must contain extracted `.md` files.
- **Re-ranking**:
  - Integrated `CrossEncoder`.
  - **Requirement**: Model download (~80MB) on first use.

## 2. Text Extraction Integration (Implemented)
- **Pipeline Integration**: `pipeline.py` and `test_rag.py` now explicitly call `text_converted.process_folder(DOCS_DIR)`.
- **Robust Pipeline**: This ensures OCR and Markdown conversion happen automatically before RAG indexing.
- **Format**: `.md` files are the source of truth for RAG.

## 3. Configuration & Secrets
- **Environment Variables**:
  - `GEMINI_API_KEY`: Required.
  - `RAG_SEARCH_K`: Default 10 (Env var control enabled).
  - `RAG_RERANK_K`: Default 5 (Env var control enabled).
- **Paths**: `DOCS_DIR`, `CHROMA_DB_DIR`.

## 4. Dependency Updates
- **New Packages**: `rank_bm25`, `sentence-transformers`, `langchain-chroma`, `langchain-huggingface`.
